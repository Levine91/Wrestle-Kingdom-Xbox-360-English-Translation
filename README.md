# Wrestle Kingdom (Xbox 360) - English Translation

I've been working on this on and off for the past 2 years.
All text was edited by hand using a hex editor (ImHex).
Edited tex graphics were through photoshop.
Tested and working on a real Xbox 360 as well as Xenia.
Only time AI was ever used was to recalculate pointers when renaming the moves in CAW, as there was hundreds that had to be changed for this alone.

You will need to dump your legally obtained ISO of the game.
You will then need to extract the folders & files from the ISO before being able to replace them with the English Translation.

Download the .zip from the latest release.
Extract the "dat" folder and "default.xex" file on the root of the disc, replacing your existing Wrestle Kingdom files.

You can either then launch the .xex file from your modded 360 or using Xenia.
Alternately, use one of these methods to repack the ISO:
https://consolemods.org/wiki/Xbox:ISO_Extraction_%26_Repacking

<b>What's Translated?</b>
- Wrestler Names
- Moves/Taunts
- Loading Screen Tips
- Wrestler Card Bios (~70%)
- Wrestler Main Menu Mini Bios
- Drama Menus
- Workout/Training Menus & Descriptions 
- Drama Mode Mentor Names & Bios (Bios need to be re-written)
- Drama Mode Fake Wrestlers Names & Bios
- Match Type Menus
- Ring Select Menu
- Match Options Menu
- Card Menu
- Options Menu
- CAW Menus & Items
- Questionnaire prior to CAW
- Pause Menu
- Tutorial
- Help Text/Menu Descriptions

<b>What's NOT Translated?</b>
- Drama Mode Dialog (Way text is coded for this section is completely different to the rest of the game)
- Achievements (Unsure if it's safe to translate them)
- Xbox Live menu (Unable to test this aspect, not sure how much is needed)
